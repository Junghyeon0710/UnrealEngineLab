# UnrealEngineLab

Unreal Engine 최적화, 성능 분석, 공식 문서 정리, 신기능 및 궁금했던 기능들을 직접 테스트하고 기록하는 저장소입니다.

엔진 기능을 실험하면서 필요한 C++, CS, 설계 관련 내용도 함께 정리합니다.

## CS

게임 클라이언트 개발에 필요한 CS 개념을 Unreal Engine과 연결해서 정리합니다

### Design

- [SOLID 원칙](Docs/CS/SOLID.md)


## 프로젝트 구성

- `Config/` — Unreal Engine 프로젝트 설정
- `Plugins/` — 프로젝트에서 사용하는 플러그인
- `Source/` — 프로젝트 C++ 코드
- `Docs/` — 공부한 내용과 분석 기록
